# F24 Port to 1.20.1 (v3)

Milestone: v3 · Release: v3 · Status: todo · Depends on: F23

## Why

1.20.1 is still one of the most played modded versions, and FlatEdit+ has no build for it: Flatgen would be the only
superflat editor there.

## Acceptance criteria

- [ ] Nodes `1.20.1-forge` and `1.20.1-fabric` (Java 17; Forge through ModDevGradle's legacyforge plugin, its jar
  also loading on NeoForge 47.1 as Glowline's does).
- [ ] Version tree `src/1.20.1` for what differs below 1.21.1; no `//? if <1.21` scattered through shared code where
  a tree class is clearer.
- [ ] Every feature works on both nodes; tests and play tests green.

## Design

- Check first: the World tab and `WorldCreationUiState` exist from 1.20 (the tabbed Create World screen); whether
  Forge 47 has `RegisterPresetEditorsEvent` (otherwise the shared mixin of F18 serves Forge).
- Shared code has been Java 17 since F00, so no language changes are needed.
- Forge joins the loaders: the Stonecutter constants, the platform halves of `common.gradle.kts` and the loader APIs
  of `BoundariesTest`; a `forgelike` half for what NeoForge and Forge share only if they do share code.

## Tests

- `./gradlew build` on all nodes; play tests on the 1.20.1 nodes.
