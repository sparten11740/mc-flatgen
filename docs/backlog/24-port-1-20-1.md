# F24 Port to 1.20.1 (v3)

Milestone: v3 · Release: v3 · Status: done · Depends on: F23

## Why

1.20.1 is still one of the most played modded versions, and FlatEdit+ has no build for it: Flatgen would be the only
superflat editor there.

## Acceptance criteria

- [x] Nodes `1.20.1-forge` and `1.20.1-fabric` (Java 17; Forge through ModDevGradle's legacyforge plugin, its jar
  also loading on NeoForge 47.1 as Glowline's does).
- [x] Version tree `src/1.20.1` for what differs below 1.21.1; no `//? if <1.21` scattered through shared code where
  a tree class is clearer.
- [x] Every feature works on both nodes; tests and play tests green.

## Design

- Shared code has been Java 17 since F00, so no language changes were needed.
- Built on the branch `port/more-versions` with the other ports (F25's decision).
- The World tab, `WorldCreationUiState` and `PresetEditor` are all in 1.20.1, so F18's shared mixin is Forge's way in
  too; Forge finds it in the jar's manifest, and the Forge build names its refmap in Forge's copy of the config, as
  Mixin finds a refmap only by that name and Forge runs the game with its intermediate names.
- Forge joins the loaders: the `forge` constant, its platform half (`platform/forge`: an entry point that wires the
  client only on a client, as Forge constructs mods on servers too, and the GameTests' holder), `BoundariesTest`'s
  loader packages, and `build.forge.gradle.kts` after Blockpilot's and Glowline's, with the `mods.toml` and the
  `pack.mcmeta` Forge 1.20.1 needs to serve a mod's resources. Nothing is shared with NeoForge but the metadata's shape,
  so there is no `forgelike` half.
- 1.20.1 differs where `mc/` and the toolkit's base classes meet the game: a world's dimensions are a registry
  (`WorldTypes.byKey` and `of` convert), a codec's result has no plain `getOrThrow` (`FlatSettings.orThrow`) and the
  system opens a `File`, each a small `//? if` in one helper; resource ids are parsed with `tryParse`, which every
  release has. The tree
  `src/1.20.1` holds what is larger: its `GameScreen` draws its own background, as 1.20.1's screens do, and hears the
  wheel along one axis; `GuiSprites` draws Flatgen's sprites, as 1.20.1 has no atlas of GUI sprites, each stretched or
  cut in nine by the border its `.mcmeta` gives; `BlockModels` and `GameRuleValues` are 1.21.1's, one copy per range.
- Text: 1.20.1 draws TrueType fonts with stb_truetype, which sizes a font by its whole height and leaves letters
  between pixels, where FreeType sizes it by its em and snaps them. For a node with `stb_truetype=true` the build
  (`common.gradle.kts`) writes the fonts 1.21 times larger (Inter's height in ems), sets body and strong text 1.5 GUI
  pixels lower, as measured against 1.21.11, and draws the glyphs twice as finely so thin strokes do not fade; a font
  of a text style not measured fails the build; the GameTests' structures go to `structures/`. The font licence
  is named in lower case, as 1.20.1 refuses capitals in a resource's path.

## Tried

- `./gradlew build` passes on all twelve nodes, with every unit test and GameTest; the Forge jar carries its manifest
  entry, the refmap and a config that names it.
- In a dev client of each 1.20.1 node, every screen of the visual run (the dimensions, Advanced, the block, biome and
  structure pickers, the library, the templates and the question) looks as on 1.21.11, text included, and a world
  created after making the Nether flat has Flatgen's overworld and flat Nether, checked by the server's commands.
- On Forge, Blockpilot's Flatgen commands answer, so the Forge entry point gives Blockpilot its commands; the library's
  Folder opens the presets folder in the system's file browser without an error.
- On NeoForge 47.1.106 the Forge node starts, and Singleplayer, Create New World, Superflat and Customize open Flatgen.
- `node tools/boot.mjs`, which now boots a Forge jar too, on the Forge it is built with, the oldest its metadata accepts
  and NeoForge 47.1: every node's jar booted on dedicated servers of its loader, listed, without errors naming Flatgen,
  up and stopped cleanly (1.20.1 Forge on Forge 47.4.29, Forge 47.1.0 and NeoForge 47.1.106).
- Not tried: the Forge jar in a player's game, where the refmap is used (dev clients run with the development names),
  and the narrator.

## Tests
