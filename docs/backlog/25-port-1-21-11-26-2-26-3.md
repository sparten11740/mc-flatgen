# F25 Port to 1.21.11, 26.2 and 26.3 (v4)

Milestone: v4 · Release: v4 · Status: todo · Depends on: F23

## Why

The remaining versions Blockpilot supports upward of 1.21.1, so Flatgen covers every version its test tool does.

## Acceptance criteria

- [ ] Nodes for 1.21.11, 26.2 and 26.3 on NeoForge and Fabric, as Blockpilot builds them.
- [ ] 1.21.11 builds from `src/26.1` where the code matches (as Blockpilot's `src/26.1` serves 1.21.11), else from a
  tree of its own.
- [x] On 26.2 and later, vanilla's `flat_all_dimensions` world type works with Flatgen and is offered as a built-in
  (moved from F22).
- [ ] Every feature works on every node; tests and play tests green.

## Design

- Flat All Dimensions is not told by its key: any world type of the game or a data pack whose Nether or End is flat as
  well as its overworld is both. Customize opens Flatgen on it (`mc/WorldTypes.flatUnderneath`, F18's test widened:
  each other dimension the Default world type's or, for the Nether and the End, flat), and the library offers it as a
  built-in beside the game's flat presets (`library/WorldTypePresets`, a new `PresetSource`), named as the game names
  the world type, its top block as icon, with a stack for each flat dimension. So 26.2's own type appears with no
  version check, and a fixture world type with every dimension flat tests both on every version. The game's 26.2 does
  not list the type on the World tab (it is not in the `normal` tag), so the library is how most players will meet it.
- Letting the game make the Nether or the End of such a world type gives back the type's own flat one, as "the game's"
  for that type is.

## Tests

- `./gradlew build` on all nodes; play tests on the new nodes.
- GameTest: the fixture's world type with every dimension flat is offered as a preset with its Nether and End, the
  ones flat in the overworld only are not; on 26.2 and later the game's Flat All Dimensions is (`WorldTypeGameTests`).
