# F25 Port to 1.21.11, 26.2 and 26.3 (v4)

Milestone: v4 · Release: v4 · Status: done · Depends on: F23

## Why

The remaining versions Blockpilot supports upward of 1.21.1, so Flatgen covers every version its test tool does.

## Acceptance criteria

- [x] Nodes for 1.21.11, 26.2 and 26.3 on NeoForge and Fabric, as Blockpilot builds them.
- [x] 1.21.11 builds from `src/26.1` where the code matches (as Blockpilot's `src/26.1` serves 1.21.11), else from a
  tree of its own.
- [x] On 26.2 and later, vanilla's `flat_all_dimensions` world type works with Flatgen and is offered as a built-in
  (moved from F22).
- [x] Every feature works on every node; tests and play tests green.

## Design

- Built on the branch `port/more-versions`, stacked on `prototype/simple-editor`, decided by a panel (an engineer, a
  maintainer and a release manager) while the owner was away: the ports take the prototype's screens, so those are ported
  once rather than twice, and the version, build, platform and rules commits stay apart from screen commits, so they
  can go to `main` on their own should the owner drop the prototype.
- The nodes use the versions Blockpilot's own nodes for those releases use. 26.2 and 26.3 build from `src/26.1`, their
  differences rename rules (the slime's package, `EntityTypes`, the concrete colours, the structure template manager)
  and small `//? if` blocks: from 26.2 the game's GUI holds the shown screen (`mc/Screens`, and Fabric's hook for a
  screen that opened, `SetScreenMixin`); from 26.3 GLFW is gone (keys by `InputConstants`), a biome's mob spawns and
  sky colour are environment attributes, folders open through `Blaze3D`, and the mouse buttons are numbered from 1, so
  the 26.x `GameScreen` translates the game's numbers into Flatgen's (`MouseButtons`).
- 1.21.11 has a tree of its own, `src/1.21.11`: it already draws, names its utilities and runs client tasks as 26.1
  does (those checks and renames now start at 1.21.11), but it still bakes block models and tints them by block
  colour, renders screens rather than extracting them, and builds game rules from feature flags, so its
  `BlockModels`, `GameScreen` and `GameRuleValues` differ from 26.1's, one copy per range as plan 3.2 says.
- Flat All Dimensions is not told by its key: any world type of the game or a data pack whose Nether or End is flat as
  well as its overworld is both. Customize opens Flatgen on it (`mc/WorldTypes.flatUnderneath`, F18's test widened:
  each other dimension the Default world type's or, for the Nether and the End, flat), and the library offers it as a
  built-in beside the game's flat presets (`library/WorldTypePresets`, a new `PresetSource`), named as the game names
  the world type, its top block as icon, with a stack for each flat dimension. So 26.2's own type appears with no
  version check, and a fixture world type with every dimension flat tests both on every version. The game's 26.2 does
  not list the type on the World tab (it is not in the `normal` tag), so the library is how most players will meet it.
- Letting the game make the Nether or the End of such a world type gives back the type's own flat one, as "the game's"
  for that type is.

## Tried

- `./gradlew build` passes on all ten nodes, with every unit test and GameTest.
- In a dev client of each of the six new nodes: the editor with every screen of the visual run (the dimensions,
  Advanced, the block, biome and structure pickers, the library, the templates and the question); on 26.2 Flat All
  Dimensions from the library, on 1.21.1 Customize on the fixture's All Flat world type.
- Trying the editor on 1.21.1 and 26.1 again found that routing screens through `mc/Screens` had broken them before
  26.2 (the helper called itself); fixed, and both tried again.
- On each new node, a world created after making the Nether flat in Flatgen has Flatgen's overworld (grass on dirt on
  bedrock from Y -64) and its flat Nether (netherrack up to Y 31, air above), checked by the server's commands.
- Not tried in game on the new nodes: the narrator.

## Tests

- `./gradlew build` on all nodes; play tests on the new nodes.
- GameTest: the fixture's world type with every dimension flat is offered as a preset with its Nether and End, the
  ones flat in the overworld only are not; on 26.2 and later the game's Flat All Dimensions is (`WorldTypeGameTests`).
